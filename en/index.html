The central thesis

A strong model does not eliminate systems engineering

A model call only produces an output conditioned on context. It does not open a browser, apply a patch, confirm a transaction, or know on its own that a task is complete. The harness turns inference into controlled work.

agent system ≈ model + harness + environment

This is not a formal identity. It is a mental model for separating three sources of behavior: learned capability, control logic, and external state.
