Abrir capítulo

A tese central

Um bom modelo não elimina engenharia de sistemas

Uma chamada ao modelo só produz uma saída condicionada ao contexto. Ela não abre um navegador, aplica um patch, confirma uma transação nem sabe, sozinha, se uma tarefa acabou. O harness transforma inferência em trabalho controlado.

sistema de agente ≈ modelo + harness + ambiente

Essa não é uma identidade formal. É um modelo mental para separar três fontes de comportamento: capacidade aprendida, lógica de controle e estado externo.
